================================================================================
          ACTIVKLASS MOBILE - ANDROID STUDIO EMULATOR SETUP GUIDE
================================================================================

This guide walks you through setting up and running the ActivKlass Mobile app 
inside an Android Studio Virtual Device (emulator) on your PC.

No Python, database, or backend installation is required! The mobile app 
connects directly to our live Firebase cloud database.

--------------------------------------------------------------------------------
PART 1: PREREQUISITES FOR YOUR PC
--------------------------------------------------------------------------------
Make sure you have these two installed first:
1. Node.js (LTS version 20 or 22):
   Download and install from: https://nodejs.org/
2. Git:
   Download and install from: https://git-scm.com/


--------------------------------------------------------------------------------
PART 2: SETTING UP ANDROID STUDIO & THE EMULATOR
--------------------------------------------------------------------------------
1. Download and install Android Studio:
   https://developer.android.com/studio
   (During installation, keep the default options checked, including 
   "Android Virtual Device").

2. Open Android Studio:
   - On the welcome screen, click "More Actions" -> "Virtual Device Manager"
     (or open any blank project and go to Tools -> Device Manager).

3. Create a Virtual Phone:
   - Click "Create Device" (or "+").
   - Select "Phone" -> pick "Pixel 7" or "Pixel 8", then click "Next".
   - Under "Release Name", pick "VanillaIceCream" (API 35) or "UpsideDownCake" 
     (API 34). Click the download arrow next to it if not yet downloaded.
   - Click "Next", then "Finish".

4. Launch the Emulator:
   - Click the "Play" (▶) button next to your virtual device.
   - A realistic Android phone window will boot up on your desktop!
   - Keep this phone window open on your screen while testing.

5. (Important) Enable Environment Variables in Windows:
   - In your Windows search bar, type "env" and click "Edit environment 
     variables for your account".
   - Under "User variables", check if "ANDROID_HOME" exists. If not, click "New":
       Variable name:  ANDROID_HOME
       Variable value: %LOCALAPPDATA%\Android\Sdk
   - Under "User variables", select "Path" -> click "Edit" -> click "New":
       Add: %LOCALAPPDATA%\Android\Sdk\platform-tools
   - Click OK to save.


--------------------------------------------------------------------------------

--------------------------------------------------------------------------------

    git clone <GITHUB_REPO_URL>
    cd activklass-mobile

2. Create a file named ".env" in the root of the "activklass-mobile" folder
   (must be named exactly ".env" with the leading dot).

3. Paste this exact configuration into your ".env" file:

4. Install the app dependencies:

    npm install


--------------------------------------------------------------------------------
PART 4: LAUNCH THE APP IN YOUR ANDROID STUDIO EMULATOR
--------------------------------------------------------------------------------
1. Make sure your Android Studio emulator is running on screen.
2. In your terminal inside "activklass-mobile", run:

    npx expo start

3. In the terminal, press the "a" key (for Android).
4. Expo will automatically:
   - Detect your running Android Studio emulator.
   - Install the Expo Go companion client onto the emulator.
   - Bundle and boot ActivKlass on the phone screen!

(Whenever you make edits or want to reload the screen, just press "r" in the 
terminal or double-tap "r" on the emulator keyboard).

--------------------------------------------------------------------------------
TROUBLESHOOTING
--------------------------------------------------------------------------------
- "VT-x / AMD-V is disabled in BIOS":
  If Android Studio fails to start the emulator, restart your PC, enter 
  BIOS/UEFI, and turn on "Intel Virtualization Technology" or "SVM Mode".

- "No Android connected device found":
  Make sure the emulator window is fully booted to the home screen before 
  pressing "a" in the terminal.

- "Network Error" or screens stay blank:
  Ensure you created the .env file in the root folder and restarted 
  "npx expo start".
